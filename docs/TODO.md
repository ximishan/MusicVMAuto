## v0.3 - 50 台 VMware

两种方案现场二选一：

1. **Guest Agent 模式（推荐）**：同一个 EXE 部署到 A-1 ~ A-50，各 VM 自己在 00:00 执行。
2. **Host Controller 模式**：宿主机依次切换 A-1 ~ A-50，再驱动当前 VM。

Guest Agent 更不受 VMware 标签位置、远程桌面分辨率和窗口遮挡影响。
