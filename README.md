# MusicVMAuto

用于 VMware Workstation 多虚拟机中的音乐客户端自动化。当前先做 **QQ 音乐**，后续兼容 **酷我音乐**。

## 现在采用的架构

**程序只运行在 VMware 外面的宿主机。虚拟机内部不安装 Python、不下载源码、不额外驻留程序。**

宿主机通过 VMware 窗口完成鼠标/键盘操作：

1. 进入当前虚拟机。
2. 代理工具切到第二个 Tab `线路设置`。
3. 只点击 `验证所有IP`。
4. 后续会自动判断 `√`，失败最多重试 3 次。
5. 双击虚拟机桌面上的 QQ 音乐图标。
6. 等待 QQ 音乐加载并处理弹窗。
7. 两个歌单按日期循环：
   - 2026-08-12：歌单1
   - 2026-08-13：歌单2
   - 2026-08-14：歌单1
   - 后续继续 1 / 2 循环
8. 最终扩展为 A-1 ~ A-50 依次执行。

## 当前可测试版本：宿主机 Demo

先只测试当前选中的 A-1，不要一次跑 50 台。

在 VMware 所在的宿主机下载本仓库，然后执行：

```bat
pip install -r requirements-host.txt
python host_demo.py
```

### 首次校准

保持 VMware Workstation 打开并选中 A-1。宿主机 Demo 中依次记录：

- `线路设置（第二个Tab）`
- `验证所有IP`
- `桌面 QQ音乐图标`
- `第1个歌单`
- `第2个歌单`

点击“记录位置”后有 4 秒，把鼠标移动到目标位置中央即可，不需要点击。坐标按 **VMware 窗口的相对位置** 保存，因此 VMware 窗口小幅移动不会影响。

### 推荐测试顺序

先点：

```text
1. 测试 IP 点击
```

确认程序只做：

```text
线路设置 → 验证所有IP
```

这一版先人工观察是否出现 `√`，不要直接完整执行。

然后再测试：

```text
2. 测试打开 QQ音乐
3. 测试今日歌单
```

最后才测试：

```text
完整演示（当前VM）
```

## 安全约束

代理工具自动化只允许操作：

```text
线路设置
验证所有IP
```

不会自动点击重新加载线路、删除 IP、验证选中 IP 或其他线路操作。
