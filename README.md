# MusicVMAuto Demo

Windows 虚拟机里的音乐客户端自动化 Demo。当前版本先做 **QQ 音乐**，后续预留 **酷我音乐** 适配器。

## 当前 Demo 做什么

在“当前这台虚拟机”内部运行：

1. 找到代理工具窗口（默认匹配“老鱼”）。
2. 强制切换到第二个 Tab：`线路设置`。
3. **只点击** `验证所有IP`。
4. 等待 IP 可用标记 `√`；失败时只重复点击 `验证所有IP`，最多 3 次。
5. IP 正常后启动 QQ 音乐。
6. 尝试关闭 QQ 音乐的独立弹窗。
7. 根据日期在两个歌单之间轮换：
   - 基准日 2026-08-12：歌单 1
   - 2026-08-13：歌单 2
   - 2026-08-14：歌单 1
   - 之后继续 1/2 循环
8. 双击今天对应的歌单。

> 这个 Demo 先验证“单台 VM 内部流程”。确认稳定后，再加 VMware 主控层去管理 A-1 ~ A-50，或者把同一个 Agent 批量部署到 50 台 VM。

## 为什么这样设计

- 不依赖 QQ 音乐桌面图标的固定坐标：优先直接找 QQ 音乐快捷方式/进程。
- 代理工具优先使用 Windows UI Automation，通过文字找 `线路设置` 和 `验证所有IP`。
- QQ 音乐歌单位置使用“相对 QQ 音乐窗口坐标”，只需要首次校准一次。
- 音乐客户端抽象成 Adapter，未来增加 `KuwoAdapter` 不需要重写代理/IP/调度逻辑。

## 安装

建议 Windows 10/11 + Python 3.10~3.12。

```bat
pip install -r requirements.txt
python main.py
```

## 第一次使用

1. 在一台测试虚拟机中运行 `python main.py`。
2. 点击“测试 IP 验证”，确认程序能自动切换到 `线路设置` 并点击 `验证所有IP`。
3. 点击“启动 QQ 音乐”。
4. QQ 音乐加载后，点击“记录歌单1位置”，然后在 3 秒内把鼠标移到第一个歌单文字中央。
5. 同样记录“歌单2位置”。
6. 点击“测试今日歌单”。
7. 确认无误后点击“完整测试当前虚拟机”。

配置会保存在 `config.json`。

## 命令行自动运行

校准完成后可以直接：

```bat
python main.py --run-once
```

这个入口后续可以直接挂到 Windows 任务计划程序的每天 00:00。

## 打包 EXE

```bat
build.bat
```

输出：`dist\MusicVMAutoDemo.exe`

## 当前还需要现场验证的地方

不同版本的“老鱼”代理工具控件结构可能不同。如果 UI Automation 读不到 `√`，下一步会加区域截图/模板识别作为兜底。

QQ 音乐偶发弹窗目前优先按独立弹窗和常见按钮文字关闭。等拿到实际弹窗截图后，可以补精确规则，避免误点主窗口。
